parsec

2× the context. ½ the cost.

parsec runs a local proxy on 127.0.0.1 that curates the context your Claude clients send. Model traffic still leaves from this machine with your own credentials.

what this installs

  • the parsec binary at /usr/local/parsec and ~/.parsec/bin, on your PATH
  • routing for the Claude clients found on this Mac — Claude Code, Codex CLI, opencode, pi, Claude Desktop — each one a choice you can untick
  • a menu-bar app with live status

what it will ask for

  • your password, once — the standard Installer prompt. The Claude Desktop step uses it to trust mitmproxy's certificate, so no second prompt appears later.
  • one toggle, Claude Desktop only — macOS requires you to approve the "Mitmproxy Redirector" network extension in System Settings. The installer opens the pane; the menu-bar app waits for the switch and finishes the setup.

Undo anytime: parsec disable <tool> · sudo /usr/local/parsec/uninstall.sh
