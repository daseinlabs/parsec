claude desktop, in detail

Desktop has no endpoint setting, so parsec reaches it by process-scoped TLS interception. Only Cowork / Agent mode and the model list are routed; normal chat, login, and the Cowork bridge pass straight through. Your credentials are forwarded verbatim — the proxy adds no auth header.

If Homebrew has to install mitmproxy, "Running package scripts…" can sit for a few minutes. That is expected.

The one step macOS will not let an installer do: System Settings → General → Login Items & Extensions → Network Extensions → Mitmproxy Redirector → on. The menu-bar app waits for it and starts intercepting the moment it flips. Then quit Claude Desktop completely (⌘Q) and reopen it.

requirements

  • Apple silicon, macOS 13 or later
  • Claude Code, Codex, opencode, or pi already installed for their choices (a missing tool is skipped and noted, never an error)
  • Homebrew, for the Claude Desktop choice
