# getparsec — logo files

The mark: two sightlines converging on a star — the parsec parallax angle.
Symmetric about the horizontal axis. No wordmark.

## Colors
- Phosphor green (primary, on dark): `#4AF626`
- Void (background): `#0A0E0C`
- Panel (tile surface): `#0F1512`

## Files

### svg/ (vector masters — use these wherever possible)
- `parsec-mark-flat.svg` — the mark, single flat color, transparent. The master.
- `parsec-mark-glow.svg` — same mark with the phosphor glow, for screen/hero use.
- `parsec-icon-512.svg` — rounded app-icon tile with the mark (dark).
- `parsec-favicon-32.svg` / `parsec-favicon-16.svg` — thicker strokes for tiny sizes.

### png/ (raster exports)
- `parsec-mark-glow-dark.png` — glow mark on the dark void (hero look).
- `parsec-mark-glow.png` — glow mark, transparent.
- `parsec-mark-flat.png` — flat mark, transparent.
- `parsec-icon-1024.png`, `parsec-icon-512.png` — app icon / marketplace.
- `parsec-favicon-64/32/16.png` — browser tab / favicon.

## Usage notes
- Prefer the SVGs; PNGs are for places that can't take vectors.
- Keep the star centered on the axis — the mark is symmetric top-to-bottom.
- Clear space: keep at least one sightline-gap clear on all sides.
- Don't recolor per-campaign, rotate, or stretch the mark.
